# NELLZ DESIGN

Сайт-портфолио дизайнера **nellz**: аватарки, баннеры и анимированные эмодзи для Telegram.

**Живая версия:** https://nellzdsg.github.io/nellz-design/

Оформление: чёрный холст, violet-акцент, хромированная типографика под стиль работ.
Сайт полностью статический: ни бэкенда, ни сборки в рантайме, ни внешних CDN.

---

## Структура

```
index.html            главная
portfolio.html        галерея работ: фильтры, лайтбокс, живые эмодзи
services.html         услуги, цены и калькулятор заказа
about.html            обо мне, соцсети
faq.html              частые вопросы (+ разметка FAQPage)
contact.html          контакты
404.html              страница ошибки
en/                   английская версия — те же семь страниц

css/tailwind.css      собранные стили (не редактировать вручную)
src/input.css         исходник стилей: токены дизайн-системы и компоненты
js/site.js            вся логика сайта: меню, анимации, фильтры, лайтбокс, калькулятор
js/vendor/lottie.min.js   проигрыватель Lottie (локально, без CDN)
js/lottie/*.json      анимированные эмодзи (распакованные .tgs)
assets/img/           оптимизированные картинки (webp)
assets/fonts/         Inter и JetBrains Mono в woff2, только latin + cyrillic
scripts/              скрипты обработки исходников
robots.txt            sitemap.xml   служебные файлы для поисковиков
```

## Как вносить правки

**Стили.** Правьте `src/input.css`, затем соберите:

```bash
npm install        # один раз
npm run build      # css/tailwind.css
npm run dev        # то же, но с отслеживанием изменений
```

Node нужен только для сборки стилей. На хостинге никакого Node нет.

**Тексты** — прямо в HTML-файлах. Правки нужно вносить в обе версии: в корне (русскую) и в `en/` (английскую).

**Новая работа в портфолио:**
1. положите оригинал в `моё-портфолио/аватарки` или `моё-портфолио/баннеры`;
2. добавьте файл и его «слаг» в списки `AVATARS` / `BANNERS` в `scripts/optimize_images.py`;
3. выполните `py scripts/optimize_images.py` — появятся thumb и full в `assets/img/works/`;
4. добавьте плитку в `portfolio.html` и `en/portfolio.html` по образцу соседних.

**Новый анимированный эмодзи:**
1. положите `.tgs` в `моё-портфолио/анимированные эмодзи`;
2. выполните `py scripts/prepare_lottie.py` — файлы появятся в `js/lottie/`;
3. добавьте плитку в галерею с атрибутами `data-lottie` и `data-lottie-src`.

## Публикация

GitHub Pages раздаёт ветку `main` из корня репозитория. Достаточно запушить изменения.

## Что важно помнить

- `404.html` использует `<base href="/nellz-design/">`, иначе GitHub Pages открывает её
  по любому несуществующему адресу и относительные пути ломаются. **При переезде на свой
  домен эту строку нужно поменять** (и заодно добавить `CNAME`).
- Адреса сайта в `canonical`, `hreflang`, `og:url` и `sitemap.xml` тоже привязаны к
  `nellzdsg.github.io/nellz-design/` — при смене домена их нужно обновить.
- `node_modules/`, папки с исходниками и `assets/original/` в репозиторий не попадают
  (см. `.gitignore`).
- Если JS отключён, FAQ и галерея продолжают работать, а блоки с анимацией появления
  показываются сразу — за это отвечает `<noscript>` в каждой странице.
